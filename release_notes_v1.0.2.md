## Rinswa Browser v1.0.2 (Official Stable Release)

Welcome to the **Rinswa Browser 1.0.2 Stable** release! Powered by the modern, battle-tested **Mozilla Gecko 157.0.1** release engine, Rinswa delivers blazing-fast performance, uncompromising privacy, and a breathtaking **Cyber-Glass** aesthetic overhaul.

---

### 🚀 Key Improvements & Highlights in v1.0.2

* **☀️ Windows Light Mode & Contrast Overhaul:**
  - Resolved contrast issues where text and options were unreadable when Windows Light Mode was active.
  - Enhanced panel background color tokens and shadow DOM styling for crisp readability in all system modes.

* **🌄 Dynamic Wallpapers & Custom Backgrounds:**
  - Fully enabled custom new tab wallpapers and solid background colors without interference from default root overlays.
  - Ships with the high-resolution **Alpine Sunset** wallpaper pre-installed.

* **🛡️ Ad Blocker Toggle in `about:preferences`:**
  - Added a dedicated **Ad Blocker (uBlock Origin Integration)** setting section directly inside `about:preferences#privacy`.
  - Built directly into the standalone installer package manifest and pinned to the primary navbar out-of-the-box.

* **📑 Smart Window Tab Groups for Fresh Installations:**
  - Configured enterprise distribution policies (`policies.json`) and branding preferences so the **Smart Window group tabs button** and switcher widget appear automatically on fresh installs.

* **🧹 Menu & UI Polish:**
  - Eliminated awkward blank spaces and gap rows in `#appMenu-popup` for a clean, compact navigation experience.

* **⚡ 1-Click Firefox Upstream Tracking & Versioning:**
  - Added `Check-Firefox-Update.bat` to automatically detect upstream Mozilla Firefox releases, bump versions across the project, and transition into `Build-Rinswa-Stable.bat`.

* **🌐 Interactive Cyber-Glass Web Showcase:**
  - Transformed the project homepage (`index.html`) into an interactive browser simulator with live theme presets (*Cyber-Glass Dark*, *Windows Light Glass*, *Midnight OLED*, *Alpine Sunset Glow*, *Neon Cyberpunk*).
