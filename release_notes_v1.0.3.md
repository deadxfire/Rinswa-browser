## Rinswa Browser v1.0.3 (Official Stable Release)

Welcome to the **Rinswa Browser 1.0.3 Stable** release! Powered by the modern, battle-tested **Mozilla Gecko 157.0.1** release engine, Rinswa delivers blazing-fast performance, uncompromising privacy, and a breathtaking **Cyber-Glass** aesthetic overhaul.

---

### 🚀 Key Improvements & Highlights in v1.0.3

* **💎 High-Contrast Light Mode Tab Text Readability:**
  - Resolved low-contrast tab labels when running in light mode or with the default theme under light appearance.
  - Active tabs now render with pure white text (`#ffffff`), glowing cyan accents, and clear drop shadows. Inactive tabs feature crisp bright slate text (`#cbd5e1`), ensuring 100% legibility over obsidian-glass gradients in all environments.
  - Close buttons, new tab buttons, and navigation bar controls retain high-contrast light colors in light mode.

* **🎯 App Menu Layout & Visual Overhaul (Matching Target Design):**
  - Expanded panel width to 360px so keyboard shortcuts are never clipped.
  - Streamlined item list: hidden `New Smart Window`, `New Classic Window`, `Passwords`, `Translate Page...`, and `Chats History`.
  - Native `Tab groups` navigation button cleanly integrated into the primary menu row.
  - Added separator above Zoom controls.
  - Direct keyboard shortcut accelerators (`Ctrl+T`, `Ctrl+N`, `Ctrl+Shift+P`, `Ctrl+J`, `Ctrl+Shift+A`, `Ctrl+P`, `Ctrl+S`, `Ctrl+F`, `Ctrl+Shift+Q`) rendered in vibrant cyan (`#38bdf8`).
  - High-fidelity SVG chevron navigation arrows for all submenus (`History`, `Bookmarks`, `Tab groups`, `More Tools`, `Help and Report`).
  - Polished colorful accent icons for every menu item matching the signature cyber aesthetic.

* **🎨 Official Theme Localization:**
  - Default theme officially named **"Rinswa Theme"** in add-ons and theme pickers, with complete freedom to switch to Light, Dark, or third-party themes.

* **🛡️ Zero-Flicker Wallpaper Engine:**
  - Synchronous wallpaper detection eliminates the brief flash of the default background when opening new tabs.
